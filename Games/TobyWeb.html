New Features

  • Added optional Vinetrap-style mobile controls to every game and runner, disabled by default.
  • Changed the default site theme to Chapter 5.
  • Added new filters to the Mods and Extras tabs.
  • Added a downloadable single-file launcher that loads game files from the Toby Web GitHub CDN.

Fixes & Improvements

  • Updated Deltarune: Sword Route to version 3.3 and fixed its Chapter 1 progression crash.
  • Updated Chapter 5 and repaired WebGL shaders that made some areas render too dark.
  • Removed TS!UNDERSWAP while its web runner remains unstable.
  • Fixed the single-file launcher to keep games in-page and correctly resolve GameMaker and CDN asset paths.
  • Fixed audio and game speed in Undertale Red & Yellow and DR Chapter 1 Noelle Edition.
  • Fixed duplicate menu hover sounds and cleaned up the Settings menu.
  • Expanded the in-site credits for the newest mods and web ports.
